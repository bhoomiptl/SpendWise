# SpendWise

SpendWise is a student-focused personal finance management application designed to help students track, understand, and plan their spending.

## Vision

> Spend wisely, not merely less.

SpendWise goes beyond basic expense tracking by turning transaction data into understandable spending patterns and financial planning tools.

## Core Features

- Income and expense tracking
- Category-wise spending analysis
- Transaction history
- Budgets and spending alerts
- Financial analytics
- Spending insights
- Savings goals
- What-if financial simulator

## Tech Stack

- Frontend: React
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT + HTTP-only cookies
- Version Control: Git & GitHub
